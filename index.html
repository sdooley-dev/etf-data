Calculation rules

A new all-time high occurs when today's Close is strictly greater than every earlier closing price. Matching an earlier high does not count as a new record. The first row is counted as the initial record.

Gap measurement

Calendar days = date difference between consecutive record highs. Trading days = number of observed trading sessions between records. The first record has no prior gap. Dates are sorted oldest to newest.
